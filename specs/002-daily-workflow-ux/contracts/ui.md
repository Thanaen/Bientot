# UI contracts

Targets accept unsigned hour digits, a colon, and two minute digits. Surrounding
whitespace is ignored. The accepted total is 1 through 1440 minutes. Invalid text
stays visible and cannot overwrite settings. Errors are localized.

Source warnings link to today in history. Each unknown or suspended automatic
interval has its own correction action. The dialog opens as reclassification,
preserves the exact selected bounds and saves only after Apply. Existing manual
rows expose Edit. Review confirmations remain separate actions.

Before lunch-end, exact departure is hidden. Conditional guidance communicates
the existing green, orange or red result and an estimated qualifier when needed.
Source-unavailable and inactive tracking states cannot display a confident claim.
