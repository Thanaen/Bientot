Bientôt can run optional plugins (.bientot-plugin files) that the user installs from Settings › Plugins after a consent dialog listing what each one may do. A plugin is a WebAssembly module run by an interpreter inside Bientôt, with no native code, no network, no file access and fixed time and memory budgets. It can only show one card in the flyout and add commands to the command palette, as the listing describes. No plugin is installed by default and Bientôt downloads none. To test, download https://github.com/Thanaen/Bientot/releases/latest/download/focus.bientot-plugin and install it from Settings › Plugins › Install from file….
